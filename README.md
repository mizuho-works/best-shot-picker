# ベストショット整理

連写した写真・動画から「これはいらないかも」を自動で選ぶ、iPhone 向けの Web アプリです。
写真はスマホの中だけで処理し、どこにも送信しません。

**使う:** https://amanosaaan.github.io/best-shot-picker/

## 使い方

1. iPhone の Safari で上の URL を開く（共有ボタン →「ホーム画面に追加」でアプリのように使えます）
2. 「写真・動画を選ぶ」→「フォトライブラリ」→ 写真の上を指でなぞってまとめて選択（100〜300枚くらいずつがおすすめ）
3. 似た写真がグループにまとめられ、各グループのベスト以外が ✕（削除候補）になります
   - 右下の丸ボタンで ✓/✕ を切替、写真をタップで拡大（左右スワイプで送る、下スワイプで閉じる）
   - 「全部残す」でグループごと残せます
4. 「削除の手順へ進む」→ 一覧と同じ時刻の写真を写真アプリで消して、「削除した」をタップ

途中の状態は自動保存されるので、写真アプリと行き来しても続きから再開できます。

## 何を見て判定しているか

| 項目 | 内容 |
| --- | --- |
| グループ分け | 撮影時刻（1/1000秒まで）＋構図(dHash)＋色合い。1.5秒以内の連写は少し動いていても同じグループ |
| くっきり度 | ラプラシアン分散（画面を16分割し、一番くっきりした部分で評価＝背景ボケに強い） |
| 明るさ | 暗すぎ・白飛び |
| 顔 | 顔の数・目つぶり・笑顔（MediaPipe Face Landmarker を端末内で実行。設定でオフ可） |
| 動画 | 3コマのくっきり度・明るさ・長さ。1秒前後の誤操作っぽい動画も候補に |

設定で「1グループで残す数（1〜3）」「似ている判定の強さ」を変えられます。

## 制限

- iPhone の仕組み上、ブラウザから写真アプリの写真を直接削除することはできません。削除は写真アプリで行います。
- Live Photos は静止画部分だけで判定します。
- 顔チェックは顔がある程度大きく写っている写真で効きます（遠くの小さな顔は検出されないことがあります）。

## 開発

ビルド不要の静的サイトです。ローカルで動かすには:

```bash
python -m http.server 8765
```

- `js/meta.js` 撮影日時（EXIF / QuickTime）
- `js/analyze.js` くっきり度・明るさ・ハッシュ・サムネイル
- `js/face.js` 顔・目つぶり・笑顔
- `js/group.js` グループ分けと採点
- `js/app.js` 画面
